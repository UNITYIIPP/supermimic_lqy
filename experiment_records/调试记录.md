### 训练参数和代码

| 项目 | 本轮配置与实现 |
| --- | --- |
| Actor 本体观测 | `proprio`，`history_length=5`，每帧 93 维。投影重力 3、基座角速度 3、关节位置减默认位置 29、关节速度 29、上一拍动作 29。配置中的 Actor 观测 corruption 关闭。 |
| Actor 参考观测 | `causal_history`，5 帧，每帧 64 维，即参考关节位置 29、参考关节速度 29、相对骨盆姿态旋转 6D。两组历史都覆盖 `t-4` 到 `t`，首末帧相距 80 ms，重置时用首帧补齐。Actor 未来目标帧数为 0。 |
| Critic | `privileged_history`，输入 1559 维，包含世界模型表示状态、未来参考窗口、仿真上下文，再加参考基座线速度和 Actor 的两组历史。隐藏层 `256 → 128`，仅用于训练。 |
| Actor 网络与策略学习 | 参考历史经编码器压到 32 维，再与展平的本体历史拼接生成 29 维动作。编码器和解码器的隐藏层均为 `2048 → 1024 → 512 → 256`。策略学习率 `2e-4`，batch `4096`，每次 1 个 batch，想象 horizon 32，`gamma=0.99`，`lambda=0.95`，`latent_bc_weight=0.1`。 |
| 世界模型输入与结构 | `gencoord` + `structured_residual`。MLP 输入 130 维，由当前 GenCoord 状态 68、关节动作 29、仿真上下文 33 组成。上下文含足摩擦、基座质心偏移和编码器偏置。MLP 三层均为 2048，使用 LayerNorm 和 GELU。世界模型每步使用当前状态和动作。 |
| 世界模型预测与损失 | 输出 70 维。前 35 维是根部线速度、角速度和关节速度增量，用于按仿真子步系数积分位姿。后 35 维是根位置 3、根旋转 3 和关节角 29 的积分残差。训练按各通道的 `transition_scales.loss_scale` 归一化状态误差。 |
| 世界模型训练 | `lr=2e-4`，10 个 batch，每批 2048，`horizon=8`。每段用首个真实状态起步，自回归预测并监督后续 7 个状态。`buffer_size=1000`，`replay_ratio=16`，`lr_decay_iterations=0`。 |
| 数据、环境与控制 | 训练数据 `/mnt/dataset/lqi3lr/dyh/supermimic/data/evt_seed_lafan/*.npz`，checkpoint 清单共 29,384 个文件。`motion` 槽占比 100%，按 return 采样。单卡 `world_size=1`，4096 环境，环境 seed 和模型 seed 均为 42。物理步长 0.005 s，控制步长 0.02 s，MuJoCo `iterations=20`、`ls_iterations=40`，回合时长上限 10 s。29 关节动作缩放统一为 `0.25`，配置的执行器延迟为 0 步。 |
| 奖励与终止 | 根位置和姿态跟踪各 `0.5`，身体位置、姿态、线速度和角速度跟踪各 `1.0`。动作变化惩罚 `-0.1`，关节限位惩罚 `-2.0`。终止条件包含超时、参考片段结束、骨盆位置或姿态偏差。 |

历史读法和推理输入形状来自导出元数据，动力学结构及损失来自跨项目代码和 checkpoint。[策略导出](/mnt/dataset/lqi3lr/dyh/supermimic_distributed/supermimic_lqy/src/supermimic/runners/policy_export.py) · [Critic 观测](/mnt/dataset/lqi3lr/dyh/supermimic_distributed/supermimic_lqy/src/supermimic/envs/multi_task_world_model_env.py:113) · [动力学 MLP](/mnt/dataset/lqi3lr/dyh/supermimic_distributed/supermimic_lqy/src/supermimic/models.py:93) · [GenCoord 积分](/mnt/dataset/lqi3lr/dyh/supermimic_distributed/supermimic_lqy/src/supermimic/representations.py:548) · [世界模型损失](/mnt/dataset/lqi3lr/dyh/supermimic_distributed/supermimic_lqy/src/supermimic/learners/wm_learner.py:197)

### 训练结果与视频效果

| TensorBoard 指标 | Step 240,000 |
| --- | ---: |
| `Train/mean_reward` | 41.058 |
| `Train/mean_episode_length` | 500 控制步 |
| `Metrics/motion/error_anchor_pos` | 0.20283 |
| `Metrics/motion/error_body_pos` | 0.05117 |
| `Loss/state` | 0.02547 |

- **视频抽帧**　约 6–18 s 能跟随行走和转向，白色机器人和绿色参考已有可见的位置偏差。约 74–154 s 的多张抽帧里，两者位置偏差更明显。回放的定量跟踪误差和提前终止次数待采集。
- **本轮主观结论**　步态稳定性稍欠。按用户目测，这次 5 帧本体 + 5 帧参考的组合没有带来明显的仿真效果提升。5+5 是同一时间窗口的两路输入，同设置下 `1+1 → 5+5` 的收益还没有独立测量。
- **下一轮对照方向**　优先验证世界模型是否限制了闭环稳定性。保持 Actor `5+5`、训练数据与回放动作一致，先在同一批 MuJoCo 轨迹上用相同初始状态和动作序列比较世界模型第 1、4、7、16、32 步的根位置、朝向和关节速度误差，再将世界模型改动后的策略放回同一回放条件比较。历史长度可沿用同一世界模型设置做单独对照。
